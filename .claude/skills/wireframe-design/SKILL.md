---
name: wireframe-design
description: 포트폴리오 웹사이트의 와이어프레임을 설계하는 스킬. 블로그 중심 레이아웃, 사이드바, 관리자 페이지를 포함한 모든 페이지의 ASCII 와이어프레임을 생성한다. "와이어프레임 만들어줘", "레이아웃 설계", "페이지 구조 잡아줘" 요청 시 반드시 이 스킬을 사용할 것.
---

## 생성할 페이지 목록
1. 메인 (`/`) — 블로그 목록 + 오른쪽 사이드바
2. 블로그 상세 (`/blog/[slug]`) — 본문 + 사이드바
3. 소개 (`/about`) — 프로젝트, 활동, 수상
4. 갤러리 (`/gallery`)
5. 관리자 로그인 (`/admin/login`)
6. 관리자 대시보드 (`/admin`)
7. 블로그 관리 (`/admin/blog`) + 에디터
8. 프로젝트 관리 (`/admin/projects`)
9. 갤러리 관리 (`/admin/gallery`)
10. 설정 (`/admin/settings`)

## 페이지별 와이어프레임

### 1. 메인 페이지 (`/`)
```
┌──────────────────────────────────────────────────────┐
│  NavBar                                              │
├──────────────────────────┬───────────────────────────┤
│                          │  ┌─────────────────────┐  │
│  블로그 글 목록           │  │  [프로필 사진]       │  │
│  ┌──────────────────┐    │  │  이름               │  │
│  │ 제목             │    │  │  한 줄 소개          │  │
│  │ 날짜 · 태그들    │    │  └─────────────────────┘  │
│  │ 미리보기 텍스트… │    │                            │
│  └──────────────────┘    │  ┌─────────────────────┐  │
│  ┌──────────────────┐    │  │  기술 스택           │  │
│  │ 제목             │    │  │  [React] [TS] [...]  │  │
│  │ 날짜 · 태그들    │    │  └─────────────────────┘  │
│  │ 미리보기 텍스트… │    │                            │
│  └──────────────────┘    │  ┌─────────────────────┐  │
│  ┌──────────────────┐    │  │  최근 프로젝트       │  │
│  │ ...              │    │  │  · 프로젝트1         │  │
│  └──────────────────┘    │  │  · 프로젝트2         │  │
│                          │  └─────────────────────┘  │
│  [이전] [1][2][3] [다음] │                            │
├──────────────────────────┴───────────────────────────┤
│  Footer                                              │
└──────────────────────────────────────────────────────┘
```
- 좌우 비율: 본문 65% / 사이드바 35%
- 모바일: 사이드바 숨김 (또는 상단으로 이동)

## 반응형 메모
- 모바일(< 768px): 사이드바 숨김, 네비게이션 햄버거 메뉴
- 태블릿(768px~): 사이드바 축소 표시
- 데스크탑(1280px+): 2컬럼 레이아웃 (본문 65% + 사이드바 35%)
