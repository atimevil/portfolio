# 포트폴리오 와이어프레임

## 프로젝트 개요

### 기술 스택
| 분류 | 기술 |
|------|------|
| 프레임워크 | Next.js 14 App Router + TypeScript |
| 스타일 | Tailwind CSS + Framer Motion |
| 인증 | NextAuth.js Credentials (환경변수 비밀번호) |
| 에디터 | Tiptap (WYSIWYG, MDX 저장) |
| 다국어 | next-intl (한국어/영어) |
| 배포 | Docker + Nginx reverse proxy |
| 저장소 | 파일시스템 (DB 없음) |

### 콘텐츠 구조
```
content/
├── posts/          ← 블로그 MDX 파일 (Docker volume)
├── projects.json   ← 프로젝트 목록
├── gallery.json    ← 갤러리 메타데이터
└── settings.json   ← devMode, 프로필 정보

public/uploads/
├── gallery/        ← 갤러리 이미지 (Docker volume)
└── projects/       ← 프로젝트 썸네일
```

## 반응형 전략

| 브레이크포인트 | 레이아웃 변화 |
|---------------|---------------|
| < 768px (모바일) | 사이드바 숨김, 햄버거 메뉴, 단일 컬럼 |
| 768px~1024px (태블릿) | 사이드바 축소 표시 (30%), 네비게이션 가로형 |
| 1024px+ (데스크탑) | 2컬럼 (본문 65% + 사이드바 35%) |
| 1280px+ (와이드) | 최대 너비 1280px 제한, 가운데 정렬 |

### 모바일 특이사항
- 갤러리: 2컬럼 그리드
- About 프로젝트: 1컬럼 그리드
- 활동/수상: 1컬럼 (세로 배치)
- 관리자: 네비게이션 상단 스크롤 가능

## 컴포넌트 목록

### Layout
- `NavBar` — 상단 네비게이션, 다크모드, 언어 전환, 모바일 햄버거 메뉴
- `Footer` — @foxibu 링크, 저작권
- `Sidebar` — 프로필, 기술스택, 최근 프로젝트
- `AdminLayout` — 관리자 전용 레이아웃 + 사이드 네비게이션

### Public Pages
- `BlogCard` — 블로그 목록 카드 (제목, 날짜, 태그, 미리보기)
- `BlogPost` — MDX 렌더링 (코드하이라이팅 포함)
- `Pagination` — 페이지 이동
- `ProjectCard` — 프로젝트 카드 (썸네일, 기술 태그, 링크)
- `GalleryGrid` — 이미지 그리드 (카테고리 필터)
- `GalleryModal` — 이미지 원본 모달
- `AboutProfile` — 소개 상단 프로필 섹션
- `ActivityList` — 활동 목록
- `AwardList` — 수상 목록

### Admin
- `TiptapEditor` — WYSIWYG 블로그 에디터
- `ImageUploader` — 드래그&드롭 이미지 업로드
- `ToggleSwitch` — devMode ON/OFF 토글
- `AdminBlogList` — 블로그 글 관리 테이블
- `AdminProjectForm` — 프로젝트 추가/수정 폼
- `AdminGalleryGrid` — 갤러리 이미지 관리 그리드

### UI Atoms
- `Button` — Primary / Secondary / Danger 변형
- `Badge` / `Tag` — 기술스택, 블로그 태그
- `Modal` — 공통 모달 컨테이너
- `ThemeToggle` — 다크/라이트 모드 전환
- `LangToggle` — 한국어/English 전환
- `LoadingSpinner` — 비동기 로딩 상태
